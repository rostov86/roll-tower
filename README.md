# Башня роллов

Мобильная мини-игра для QR на пакете доставки суши. Складывайте роллы в башню: новый круг опускается, рулите наклоном телефона (или пальцем / клавишами).


Демо-бренд: СушиМаркет. Названия, слоган и палитра — в src/brand.ts.

## Запуск

Нужны Node.js 18+.

    cd roll-tower
    npm install
    npm run dev

Откройте URL из терминала, обычно http://localhost:5173. Vite слушает --host.

Сборка: npm run build, затем npm run preview. Результат в dist/.

## Ребрендинг

Правите только src/brand.ts: name, gameName, slogan, colors, copy, achievements, storagePrefix, themeColor.
После правок соберите проект (npm run build). Иконки: scripts/gen-icons.mjs или замените public/icons и public/icon.svg. Синхронизируйте public/manifest.webmanifest.

## Статический хостинг

Раздавайте dist/ по HTTPS (нужно для iOS motion и vibrate). base относительный — можно класть в подпапку. Service worker кэширует офлайн после первого визита.

## iOS: разрешение на наклон

DeviceOrientationEvent.requestPermission вызывается по нажатию «Играть». Без разрешения игра работает пальцем, стрелками или A/D.
Первый запуск показывает подсказку «Наклони телефон». PWA: safe-area, без зума, высота 100dvh.

## Геймплей

Очки = этажи + бонус площади + комбо. Идеал: васаби, частицы, vibrate. Скорость растёт. Партия 30–90 с. Рекорд и достижения в localStorage.
Достижения: Первый этаж, 10/25/50 этажей, Идеальный ролл, Комбо x5, Гурман (3000), Мастер ножа (10 идеальных подряд).
